## 📖 О проекте

Современные офисные редакторы делятся на два лагеря:
- Инструменты реального времени без полноценного версионирования и ветвления (Google Docs, Notion).
- Системы контроля версий для разработчиков с ручным текстовым слиянием файлов (Git + Markdown), неудобные для авторов и редакторов текста.

**SyncPro** объединяет лучшие стороны обоих миров в единую экосистему:
1. **В реальном времени:** авторы совместно редактируют документ без задержек и блокировок — движок **CRDT** гарантирует строгое схождение состояния на всех устройствах, а **Redis Awareness** транслирует курсоры и онлайн-статусы.
2. **В контроле версий:** пользователи создают осмысленные коммиты, ответвляют идеи в изолированные ветки, исследуют историю через визуальный **2D DAG-граф**, выполняют **3-Way слияния** с алгоритмическим поиском общего предка (LCA) и перемещаются по истории через интерактивный Time-Travel док.
3. **В макете и типографике:** постраничный физический макет (A4, A5, Letter, книжная/альбомная ориентация), авто-пагинация, разрывы страниц (Ctrl+Enter), ввод кликом в свободную область (Click-and-Type), тонкая настройка шрифтов, размеров, палитр и выравнивания, поддержка Google Fonts и CAS-загрузки шрифтов, а также бесшовный импорт и экспорт офисных документов (`.docx`, `.odt`, `.doc`, `.txt`, `.pdf`, `.md`).

## 🌟 Ключевые возможности

### 🎨 1. Продвинутая типографика и кастомизация текста
- **Широкая библиотека шрифтов:**
  - **Без засечек (Sans):** Inter (стандартный системный), Roboto, Montserrat, Open Sans.
  - **С засечками (Serif):** Merriweather, Playfair Display, Lora, Georgia.
  - **Моноширинные (Mono):** JetBrains Mono, Fira Code.
- **Подключение Google Fonts:** моментальный поиск и интеграция любого шрифта из каталога Google Fonts по названию с динамическим подключением `@font-face`.
- **Загрузка пользовательских шрифтов с CAS-дедупликацией:**
  - Поддержка форматов `.woff2`, `.woff`, `.ttf`, `.otf` до 15 МБ.
  - **Content-Addressable Storage (CAS):** SHA-256 хеширование файла предотвращает дублирование одних и тех же шрифтов в базе данных и хранилище.
- **Инструменты верстки и типографики:**
  - Размер шрифта от `12px` до `36px`.
  - Палитра из 16 цветов текста + авто-цвет.
  - Пастельные маркеры выделения текста (Highlight).
  - Полный спектр выравнивания: по левому краю, по центру, по правому краю и по ширине (Justify).
  - Меню **«Интервалы»** (Spacing Popover):
    - **Межстрочный интервал (Line Height):** быстрые пресеты 1.0, 1.15, 1.5, 2.0 и точный ввод произвольного множителя (например, 1.35).
    - **Интервал после абзаца (Space After):** пресеты 0, 4, 8, 12, 16 px и кастомный ввод.
    - **Межбуквенный интервал (Letter Spacing / Tracking):** обычный, узкий (-0.5px), широкий (1px), очень широкий (2px) и числовой ввод.
    - Быстрое переключение: применение к текущему абзацу или ко всему документу в один клик.
  - Интерактивный диалог **«Вставить ссылку»** (`LinkDialog`): безопасный диалог вставки и редактирования ссылок с автодополнением протокола `https://`, опцией открытия в новой вкладке (`target="_blank"`), удалением ссылки, строгим белым списком безопасных протоколов (`http`, `https`, `mailto`, `tel`) и защитой от XSS/Attribute Breakout.
  - Гибридная модель применения: глобальный базовый шрифт документа с возможностью точечного переопределения для отдельных блоков и фрагментов текста.
  - **Изоляция типографики интерфейса:** стили пользовательских шрифтов применяются строго к контенту документа и изолированы от системных кнопок и панелей SyncPro.

### 🖼️ 2. Позиционирование и стилизация медиа, кода и таблиц
- **Плавающая панель форматирования изображений:**
  - Свободное позиционирование: по левому краю, по центру, по правому краю и во всю ширину.
  - Быстрое масштабирование: пресеты ширины `25%`, `50%`, `75%`, `100%` и плавный ползунок точной настройки.
  - Сохранение в формате расширенного Markdown: `![caption|width=50%|align=center](url)`.
- **Позиционирование блоков кода:**
  - Настройка выравнивания (по левому краю, по центру, во всю ширину) и ширины (50%, 75%, 100%).
- **Интерактивная стилизация таблиц:**
  - Плавающее меню настройки таблицы при клике:
    - **Внутренние отступы ячеек (Cell Padding):** компактные (4px), стандартные (8px), просторные (14px) и точный числовой ввод в пикселях.
    - **Стили границ:** сетка (Grid), только строки (Rows), без границ (None).
    - **Зебра (Striped Rows):** элегантное чередование подсветки строк таблицы.
    - **Выравнивание:** по центру, по левому краю или во всю ширину.
  - Сохранение параметров стилизации в виде мета-комментария таблицы `<!-- table padding=14 borders=none striped=true align=center -->`.

### 📑 3. Постраничный макет и процессинг документов (Google Docs & MS Word Style)
- **Физические страницы бумаги (Paged Canvas):**
  - Реалистичная визуализация документов в виде физических листов бумаги с тенями, границами и полями.
  - Поддержка международных стандартов форматов:
    - **A4** (210 × 297 мм, 794 × 1123 px).
    - **A5** (148 × 210 мм, 559 × 794 px).
    - **US Letter** (216 × 279 мм, 816 × 1056 px).
    - **Настраиваемый формат (Custom Dimensions):** произвольные размеры листа от 100 × 100 мм до 840 × 1189 мм.
  - Свободное переключение ориентации: **Книжная (Portrait)** и **Альбомная (Landscape)** с мгновенным пересчетом геометрии листов.
  - Настраиваемые поля документа: **Обычные** (20 мм), **Узкие** (12.7 мм), **Широкие** (25.4 мм) и **Пользовательские поля (Custom Margins)**.
- **Диалог «Параметры страницы» (Page Setup Dialog):**
  - Модальное окно тонкой настройки в панели «Макет»: точный ввод ширины, высоты и каждого из 4 полей (верхнее, нижнее, левое, правое) в миллиметрах.
  - Интерактивный калькулятор полезной области печати (Printable Area) в миллиметрах в реальном времени.
  - Строгие Guardrails: автоматическая блокировка некорректных значений (`NaN`, поля менее 5 мм, суммарные поля, оставляющие менее 50 мм для контента).
- **Специализированная панель инструментов «Макет» (Layout Tab):**
  - Выделенная вкладка тулбара с быстрыми селекторами формата листа, ориентации, полей, вызовом диалога настройки и зума.
  - Плавное масштабирование рабочего холста от 75% до 150% со сбросом в 100% в один клик.
- **Интеллектуальная авто-пагинация (Auto-Pagination):**
  - Непрерывный мониторинг вертикальной высоты контента относительно емкости листа ($H_{sheet} - P_{margins}$) с учетом актуального межстрочного интервала и отступов абзацев.
  - Автоматический перенос переполняющих блоков на следующую страницу (Страница 2, Страница 3...) без выхода элементов за физические границы листа.
- **Разрывы страниц (Page Breaks):**
  - Вставка принудительного разрыва страницы через кнопку панели «Макет» или клавиатурное сочетание **Ctrl + Enter**.
  - Интерактивный разделитель страниц с бейджем «Разрыв страницы» и возможностью быстрого объединения листов в один клик.
  - Полная поддержка разрывов страниц при экспорте в DOCX (`pageBreakBefore: true`) и ODT (`<text:p style:name="PageBreak"/>`).
- **Ввод текста кликом в любом месте (Click-and-Type Anywhere):**
  - Возможность начать писать текст в любой свободной области листа без необходимости создания пустых строк.
  - Интеллектуальное определение зоны клика по горизонтали с автоматическим выставлением выравнивания:
    - Клик в левой трети листа -> выравнивание по левому краю (`text-align: left`).
    - Клик в центральной трети листа -> выравнивание по центру (`text-align: center`).
    - Клик в правой трети листа -> выравнивание по правому краю (`text-align: right`).
  - Автоматическая установка фокуса и позиционирование курсора.
- **Двусторонняя синхронизация панели инструментов (Toolbar Sync):**
  - Синхронное отображение актуального кегля шрифта (16px, 24px и др.) и семейства шрифта при перемещении курсора и выделении текста.
- **Индикатор макета в реальном времени:**
  - Отображение текущего формата и ориентации в нижней панели статуса (`A4 • Книжная`, `A5 • Альбомная`, `200×250 мм • Настраиваемый`).
- **Высокоточная печать и экспорт в PDF (@media print):**
  - Изоляция полей печати, динамическое внедрение правил `@page { size: ...; margin: ... }` под текущие размеры листа и корректное разделение страниц.

### 📄 4. 100% Совместимость с популярными форматами документов
- **Microsoft Word (.docx) с поддержкой честного OpenXML и медиа:**
  - Экспорт: встроенный рекурсивный AST-парсер переводит HTML-разметку выравнивания (`<div style="text-align: center">`) и инлайн-стилей `<span style="...">` в нативные структуры `docx` (`Paragraph`, `TextRun`, `ExternalHyperlink`). **Полностью исключена утечка сырых HTML-тегов в Word!**
  - Встраивание изображений: картинки автоматически конвертируются в нативные контейнеры `ImageRun` с сохранением пропорций.
  - Импорт: распаковка и преобразование DOCX в интерактивные блоки CRDT без потери структуры.
- **OpenDocument Text (.odt):**
  - Полная поддержка стандарта OASIS ODF (LibreOffice, OpenOffice, МойОфис).
  - Экспорт: автоматическая упаковка в валидный ZIP-контейнер со встроенной папкой `Pictures/`, файлами `mimetype`, `manifest.xml`, `content.xml`, `styles.xml` и `meta.xml`.
  - Импорт: потоковый разбор текстовых секций и заголовков.
- **Markdown ZIP пакет с медиа (.zip):**
  - Полная выгрузка документа в виде архива, содержащего чистый `document.md` и папку `media/` со всеми встроенными изображениями. В тексте markdown ссылки на картинки автоматически заменяются на локальные относительные пути `media/image_1.png`. Встроена защита от Zip Slip / Path Traversal.
- **Legacy Microsoft Word (.doc):**
  - Быстрое извлечение текстовых блоков из бинарных файлов Word 97–2003 (потоки UTF-16LE и ASCII).
- **Plain Text (.txt):**
  - Чистый текстовый экспорт и импорт в UTF-8.
- **Печать и PDF (.pdf):**
  - Оптимизированный CSS-стиль для печати и экспорта в PDF через браузерный диалог с физическими размерами листа.

### ⚡ 4. Алгоритмическое ядро CRDT (Conflict-Free Replicated Data Type)
- **Детерминированное посимвольное схождение:** реализация на базе алгоритмов **YATA / Fugue** исключает интерливинг и потерю символов при одновременном вводе.
- **Логические часы Лампорта и Векторы Состояния (State Vector):** частичный и полный порядок операций без синхронизации физического времени.
- **Компактный бинарный кодек:** эффективная сериализация дельт и состояний в бинарный формат для передачи по сети и долговременного хранения.
- **Fuzzing & Chaos Resilience:** ядро валидировано стресс-тестами на 10 000+ конкурентных операций между 4 независимыми пирами.

### 🌳 5. Полноценный контроль версий (Merkle-DAG)
- **Криптографическая неизменяемость:** каждый коммит идентифицируется 64-символьным SHA-256 хешем, вычисляемым от метаданных, родительских узлов и дельты контента.
- **Автоматический корневой коммит:** создается при инициализации любого документа и служит надежным базисом истории.
- **Многодорожечная 2D визуализация графа (DAG Lanes):**
  - Каждая ветка отображается на собственной цветной дорожке (синяя для `main`, изумрудная, фиолетовая, янтарная для фиче-веток).
  - Гладкие кривые Безье для разветвлений (fork) и штриховые кривые для слияний (merge).
  - Цветные бейджи веток (`[main]`, `[feature/...]`) и динамический индикатор `(HEAD)`.
- **Изолированные ветки:** создание ветки с пользовательским именем из любой точки графа; мгновенное переключение активного текста документа при смене ветки.
- **Интеллектуальный 3-Way Merge:**
  - Алгоритмический поиск наименьшего общего предка (LCA).
  - Dry-run анализ конфликтов (автоматическое бесконфликтное слияние или интерактивное разрешение по блокам: *Ours / Theirs / Both*).
  - Фиксация объединенного текста в документе и создание Merge-коммита.
- **Time-Travel и управление историей:**
  - Плавающий адаптивный док для инспекции исторических версий.
  - **Revert:** откат документа к любой исторической точке с созданием коммита восстановления.
  - **Delete:** безопасное удаление коммитов из DAG с автоматической перелинковкой связей родителей.

### 🛡 6. Безопасность корпоративного уровня (Security Hardened)
- **Строгая валидация файлов:** проверка magic bytes для изображений (PNG, JPEG, WebP, GIF) и шрифтов (WOFF2, WOFF, TTF, OTF).
- **Защита от XSS и инъекций:** встроенный санитизатор `sanitizeHtmlForEditor` и строгий парсер инлайн-стилей `sanitizeInlineStyle`, исключающий attribute breakout, выполнение опасных схем (`javascript:`, `vbscript:`, `data:`) и инъекции CSS-правил.
- **Изоляция хранилища файлов:** раздача файлов с защитными HTTP-заголовками `X-Content-Type-Options: nosniff` и `Content-Security-Policy: default-src 'none'; sandbox`.
- **Защита от DoS:** проверка лимитов распаковки (защита от zip-бомб) и квотирование размеров загрузок.

### 👥 7. Командные пространства и живое присутствие
- **Рабочие пространства (Workspaces):** организация документов по проектам, управление участниками и ролями (Владелец, Редактор, Читатель).
- **Живое присутствие (Redis Awareness):** индикация активных соавторов онлайн в реальном времени с цветными аватарками и счетчиком активных участников.
- **Внутридокументные комментарии:** контекстное обсуждение и обратная связь в боковой панели.
- **Центр уведомлений:** оповещения о коммитах, слияниях веток и изменениях в пространствах.
- **Профиль и безопасность:** загрузка кастомных аватарок, смена пароля, защищенные HTTP-only cookies с JWT.

### ✉️ 8. Верификация Email и безопасность учетных записей
- **Обязательное подтверждение Email:**
  - Защита рабочих пространств и редактора от спама, ботов и невалидных адресов.
  - При попытке входа в `/dashboard` или `/doc/*` неактивированные аккаунты плавно перенаправляются на защищенный экран `/auth/verify-email`.
- **Двухканальный механизм подтверждения:**
  - **Мгновенная ссылка:** криптографический токен (`crypto.randomBytes(32)`), передаваемый в URL.
  - **6-значный OTP-код:** ручной ввод кода из письма с удобным полем ввода, цифровой валидацией и автофокусом.
- **Криптографическая стойкость и защита от атак:**
  - **Аппаратный PRNG:** генерация OTP через `crypto.randomInt(100000, 1000000)` исключает предсказуемость псевдослучайных последовательностей.
  - **Защита от брутфорса:** жесткое ограничение до 5 попыток ввода кода; при превышении лимита код инвалидируется в БД.
  - **Одноразовость (Replay-Proof):** ссылка и OTP могут быть использованы только один раз.
  - **Защита от спама:** кулдаун повторной отправки писем (60 секунд).
  - **Защита от enumeration:** унифицированные ответы API предотвращают определение наличия email в системе.
- **Гибкий почтовый шлюз:**
  - Отправка адаптивных HTML-писем через протокол SMTP (Nodemailer).
  - Встроенный безопасный fallback-симулятор для локальных сред разработки и тестирования при отсутствии внешнего SMTP-сервера.

### 👑 9. Панель администратора и решение проблем (Zero Leakage)
- **Строгая архитектура Zero Leakage:**
  - Обычные пользователи не видят ни одного элемента администрирования в меню, профиле или сайдбаре.
  - Любой неавторизованный запрос к `/admin` или `/api/admin/*` возвращает стандартный `404 Not Found` (перезапись на уровне Edge Middleware с криптографической проверкой подписи JWT Web Crypto API HMAC-SHA256).
- **Дашборд системных метрик в реальном времени:**
  - Мониторинг ключевых показателей платформы: общее число пользователей (активные, подтвержденные, заблокированные), распределение тарифных планов (Free / Pro / Enterprise), количество рабочих пространств, документов и коммитов в Merkle-DAG, а также суммарный объем дискового пространства в хранилище.
- **Центр управления пользователями:**
  - Интерактивная таблица пользователей с фильтрацией по статусу и тарифу, поиском по имени и email.
  - **Force Verify:** экстренная ручная верификация email пользователя в один клик.
  - **Reset Password:** генерация и безопасная отправка одноразовой ссылки для сброса пароля.
  - **Блокировка / Разблокировка:** мгновенный отзыв доступа с принудительным завершением активных сессий.
  - **Управление тарифами:** ручное присвоение планов Pro или Enterprise с установкой срока действия.
- **Управление пространствами и документами:**
  - Каталог пространств с детализацией владельцев, числа участников и документов.
  - **Передача прав владения (Ownership Transfer):** бесшовная смена владельца рабочего пространства или отдельного документа.
  - **Восстановление документов:** поддержка мягкого удаления (Soft Delete) и мгновенное восстановление удаленных документов из корзины.
- **Система промокодов (Promo Codes Engine):**
  - Встроенный генератор читаемых кодов (например, `PROMO-XXXX-XXXX`).
  - Гибкая настройка: целевой план (`pro`, `enterprise`), срок действия (дни), ограничение числа активаций (`max_uses`).
  - **Атомарная защита от Race Conditions:** условный SQL-апдейт (`UPDATE ... SET times_used = times_used + 1 WHERE ...`) предотвращает превышение лимитов активаций при конкурентных параллельных запросах.
  - Быстрое копирование промокода в буфер обмена, деактивация и удаление.
- **Журнал аудита действий (Audit Trail):**
  - Детальный лог всех административных событий: создание промокодов, смена тарифов, передача владения, блокировка учетных записей.
  - Фиксация IP-адреса администратора, целевой сущности и временной метки.

### 💳 10. Тарифные планы и квотирование ресурсов
- **Многоуровневая модель подписок:**
  - **Free:** До 100 МБ хранилища, до 3 рабочих пространств, стандартные системные шрифты, неограниченное редактирование CRDT и Merkle-DAG.
  - **Pro:** До 10 ГБ хранилища, до 20 рабочих пространств, загрузка кастомных шрифтов с CAS-дедупликацией, Google Fonts, приоритетная синхронизация.
  - **Enterprise:** До 100 ГБ хранилища, неограниченное количество пространств и документов, расширенный аудит и выделенная поддержка.
- **Кабинет управления подпиской (`/settings/billing`):**
  - Прозрачная визуализация дисковой квоты с расчетом занятого объема в байтах/мегабайтах.
  - Наглядное сравнение доступных возможностей каждого плана.
  - Форма моментальной активации промокода с автоматическим продлением или повышением плана без перезагрузки страницы.

## 🚀 Быстрый старт

### Предварительные требования
- **Docker & Docker Compose** (v24+)
- **Node.js** (v20+ или v22 LTS)
- **npm** (v10+)

### 1. Клонирование репозитория
```bash
git clone https://github.com/sloobman/syncpro.git
cd syncpro
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
*(Параметры по умолчанию настроены для локальной разработки и не требуют правок при первом запуске)*.

### 3. Запуск инфраструктуры в Docker
Поднимите контейнеры базы данных, кэша и объектного хранилища:
```bash
docker compose up -d
```

Сервисы будут доступны по адресам:
- **PostgreSQL 16:** `localhost:5432` (`syncpro` / `syncpro_secret`, БД `syncpro_dev`)
- **Redis 7:** `localhost:6379`
- **MinIO S3 API:** `localhost:9000` (`minioadmin` / `minioadmin`)
- **MinIO Web Console:** `http://localhost:9001`

### 4. Проверка готовности сервисов (Healthcheck)
```bash
# Через Node.js (кроссплатформенно):
node scripts/healthcheck.js

# Либо через PowerShell (Windows):
.\scripts\healthcheck.ps1

# Либо через Bash (Linux / macOS):
./scripts/healthcheck.sh
```

### 5. Запуск веб-приложения (Frontend)
```bash
cd frontend
npm install
npm run dev
```

Откройте в браузере: **`http://localhost:3000`**

## 🧪 Тестирование и верификация

Система покрыта многоуровневыми тестами (100% Pass) и строгими проверками качества:

```bash
# 1. Запуск всех модульных тестов (CRDT, Merkle-DAG, Конвертеры документов, Санитизация):
npm --prefix frontend test

# 2. Строгая проверка статической типизации TypeScript:
cd frontend && npx tsc --noEmit

# 3. Проверка правил линтинга ESLint (0 ошибок):
npm --prefix frontend run lint

# 4. Проверка production-сборки Next.js:
npm --prefix frontend run build
```

### Результаты автоматизированного набора тестов:
- `hashPassword & verifyPassword` — криптографическая проверка паролей bcrypt.
- `signToken & verifyToken` — безопасность и восстановление сессионных JWT.
- `LamportClock` — монотонность и witness удаленных логических часов.
- `TextCRDT YATA / Fugue` — детерминированное схождение конкурентных вставок и удалений.
- `TreeCRDT` — защита от циклов в иерархических структурах блоков.
- `BinaryCodec` — сериализация векторов состояния и бинарных операций.
- `Fuzzing & Chaos Simulation` — 10 000+ случайных конкурентных операций между 4 репликами.
- `MerkleDAG LCA` — корректность нахождения наименьшего общего предка при ветвлении.
- `ThreeWayMergeEngine` — бесконфликтное автоматическое объединение непересекающихся веток.
- `sanitizeInlineStyle` — валидация типографических стилей и нейтрализация XSS-векторов.
- `DocumentConverter.exportDocx` — построение валидного бинарного DOCX блоба.
- `DocumentConverter.exportOdt` — сборка строгого ODF ZIP-пакета с XML-структурами.
- `DocumentConverter.importFile` — корректное извлечение текста и разметки из файлов.
- `Email Verification & OTP` — криптографическая генерация токенов, ограничение попыток и защита от брутфорса.
- `Promo Codes Engine` — атомарные лимиты активаций и защита от гонок (Race Conditions).
- `Subscription Quotas` — валидация лимитов хранилища и рабочих пространств по тарифам (Free / Pro / Enterprise).
